# 初中数学题核心素养标注系统 — 架构设计

## 1. 项目概述

### 1.1 背景与目标
- **目标**：构建支持多人增量式交互标注的初中数学题核心素养与层级标注平台
- **核心机制**：基于 Coreset Selection 的主动学习（Active Learning），动态推荐高价值试题
- **标注规则**：每道题需 3 名不同标注员独立标注后才算"完全完成"
- **数据规模**：已标注 300+ 题，无标签题库 4 万余题

### 1.2 核心功能
1. **用户管理**：注册、登录、标注前培训/学习
2. **试题管理**：4 万+ 试题的存储、检索、状态追踪
3. **增量式标注**：支持多人并行标注，实时同步标注进度
4. **Coreset 推荐引擎**：增量式、动态推荐待标注核心集试题
5. **嵌入与可视化**：RoBERTa/大模型提取嵌入，t-SNE/UMAP 可视化
6. **模型训练与验证**：预置分类网络，对接后台训练，验证主动学习效果

## 3. 关键设计原则

### 3.1 高可复用性 & 可扩展性
| 设计策略 | 说明 |
|---------|------|
| **策略模式 (Strategy Pattern)** | Coreset 算法接口统一，新算法只需实现 `BaseCoresetSelector` |
| **插件化注册** | 算法类通过装饰器自动注册到算法工厂 (`@register_coreset`) |
| **抽象嵌入提取器** | `BaseEmbedder` 统一 RoBERTa / LLM / Sentence-BERT 等接口 |
| **抽象模型训练器** | `BaseModelTrainer` 统一分类头，支持多任务（素养+知识点） |
| **事件驱动架构** | 标注完成 → 触发嵌入重算 / Coreset 重推荐 / 模型重训练 |

### 3.2 增量式与异步化
- **嵌入预计算**：全量 4 万题在系统初始化时批量计算，后续增量更新
- **增量 Coreset**：新标注产生后，仅更新受影响区域的推荐分数，而非全量重算
- **异步训练**：模型训练通过 Celery Worker 异步执行，前端轮询或 WebSocket 推送进度

### 3.3 多标注员一致性
- 每道题维护 `annotation_count` 和 `annotator_ids` 列表
- 当 `annotation_count >= 3` 且 `len(set(annotator_ids)) >= 3` 时，状态变为 `COMPLETED`
- 支持 IAA (Inter-Annotator Agreement) 计算，用于质量监控

## 5. 模块职责划分

| 模块 | 职责 | 关键技术 |
|-----|------|---------|
| `auth` | 用户注册、登录、JWT 鉴权、角色权限 | FastAPI-Users / OAuth2 |
| `annotation` | 试题列表、标注界面、提交校验、状态流转 | Pydantic 校验、事务控制 |
| `coreset` | 算法接口、多种 Coreset 实现、推荐排序 | NumPy, scikit-learn, faiss |
| `embedding` | 文本向量化、批量计算、缓存管理 | transformers, ONNX, Redis |
| `visualization` | t-SNE/UMAP 降维、可视化数据接口 | sklearn, umap-learn, plotly |
| `training` | 模型定义、训练循环、评估指标、实验追踪 | PyTorch, WandB/MLflow |
| `admin` | 仪表盘、标注质量监控、用户管理 | Admin 后台或独立页面 |

## 6. 接口设计风格

- **REST API**：标准 CRUD，JSON 格式，状态码规范
- **WebSocket**：实时推送标注状态变更、模型训练进度、Coreset 推荐更新
- **API 版本化**：`/api/v1/...`
