# 易混素养对比表 V2

# 0.问题

1. 素养：多标（主素养，限制三个以内）、漏标、错标（素养理解存在偏差）
2. 层级：不一致（参考题目解析、难度）

## 1. 文档目的

本文档用于辅助数学题目核心素养打标，聚焦实际标注中最容易混淆的素养对。  
使用原则不是重复官方定义，而是帮助回答一个更直接的问题：

**这道题到底更应该标成哪一种素养？**

## 2. 素养整体介绍

本节不再复述官方定义，而是把官方定义转化成更便于题目打标的判断口径。  
核心原则是：

```text
看题目的主任务，不看题目表面元素；
看解题主路径，不看所有可能出现的知识点；
看素养是否推动解题，不看素养是否“沾边”。
```

一题可以多标，但建议控制在 3 个以内。  
主素养通常对应题目的主要难点；次素养通常对应必要但非主导的解题支撑。

### 2.1 初中阶段九项素养的可操作定义

#### 2.1.1 抽象能力

抽象能力看的是：学生是否需要从具体对象、文字材料、现实情境或若干特例中，提炼出数学对象、变量关系、一般结构或概念本质。

更容易标`抽象能力`的题：

- 从文字情境中抽出变量、关系式、一般规律；
- 从具体数、式、图形中概括出一般表达；
- 判断一个数学对象的本质属性，如相反数、倒数、绝对值、有理数与无理数、函数概念等；
- 把具体问题中的“对象”提炼为数学对象，而不只是代入公式计算。

不宜标`抽象能力`的题：

- 题目已经给出明确公式、方程、函数或图像，学生只需计算、读图或判断；
- 只是列方程解决现实问题，但核心难点在建立和使用模型，此时更偏`模型观念`；
- 只是从若干图形或数列中找规律，若主干是递推与归纳，通常更偏`推理能力`。

初中边界：

- 初中`抽象能力`强调从具体到一般、从现实到数学对象；
- 只要学生没有明显承担“提炼数学对象或一般结构”的任务，就不要因为题目有字母、变量、一般式而机械标注。

高中对应：

- 高中对应素养是`数学抽象`，要求更高，强调从数量关系、图形关系、具体背景中抽象出一般规律、概念体系和结构，并能用数学语言表征。

#### 2.1.2 运算能力

运算能力看的是：学生是否需要明确运算对象，依据法则、性质、公式或运算律进行正确、合理、较有效的计算或变形。

更容易标`运算能力`的题：

- 数值计算、代数式化简、求值、因式分解；
- 解方程、不等式、分式方程、根式条件；
- 函数表达式代入、面积体积计算、角度计算；
- 概率或统计中的基础数值计算。

不宜过度标`运算能力`的题：

- 计算只是最后一步，主干是证明、图形判断、数据解释或建模；
- 题目没有实际计算，只是判断条件、识别图像关系；
- 只是出现 `180°`、坐标、代数符号，但主任务不是算。

初中边界：

- L1 常见于单一规则或少量基础计算；
- L2 常见于多个规则组合，如整式运算加因式分解、分段计费、多步几何面积计算；
- 如果计算复杂但没有新的结构判断，仍以`运算能力`为主，不必强行加`推理能力`。

高中对应：

- 高中对应素养是`数学运算`，更强调理解运算对象、选择运算方法、设计运算程序，以及在复杂结构中完成运算。

#### 2.1.3 几何直观

几何直观看的是：学生是否需要借助图形、图像、图表、坐标或直观结构来理解问题、发现关系和确定思路。

更容易标`几何直观`的题：

- 读几何图、函数图像、坐标图、方格图；
- 由图形位置关系判断角、边、面积、相似、全等、平行；
- 用图像解方程或不等式；
- 借助图形结构发现规律，如坐标箭头路径、格点图形规律；
- 建立形与数的联系，如面积关系、图像上下关系、坐标位置关系。

不宜标`几何直观`的题：

- 只有几何概念或三角形名称，但没有图形分析任务；
- 只用几何公式直接计算，如已知菱形对角线求面积；
- 题目是纯代数、纯定义、纯数量关系，不依赖图形位置或图像结构。

初中边界：

- 图只是装饰或常规背景，通常不标；
- 图是找关系的入口，标 L1；
- 图形结构是解题主路径，且需要综合位置关系、形数结合或动态规律，标 L2。

高中对应：

- 高中对应素养是`直观想象`，范围比初中`几何直观`更宽，包含几何直观和空间想象，强调利用空间形式、图形变换和形数联系理解复杂问题。

#### 2.1.4 空间观念

空间观念看的是：学生是否需要认识、想象或表达空间物体的形状、大小、方位、位置关系和运动变化。

更容易标`空间观念`的题：

- 立体图形、三视图、展开图、折叠还原；
- 空间方位、旋转、翻折、平移后的空间关系；
- 从实物抽象几何体，或由平面图想象空间物体。

不宜标`空间观念`的题：

- 普通平面几何图、坐标平面图、方格图；
- 平面折叠题若只是在平面内分析角、边、相似关系，通常仍优先看`几何直观`和`推理能力`；
- “点在坐标系中移动”不等于空间观念。

初中边界：

- 只有三维、展开折叠、空间方位或空间运动想象成为主任务时，才稳定标`空间观念`；
- 平面图形的读图、作图、面积和相似，多数归入`几何直观`。

高中对应：

- 高中不单列`空间观念`，通常并入`直观想象`。

#### 2.1.5 推理能力

推理能力看的是：学生是否需要从事实、条件、命题或规律出发，依据规则推出结论，并能说明理由。

更容易标`推理能力`的题：

- 证明题、补全证明、平行线判定、全等相似论证；
- 由条件推出角、边、位置、取值范围；
- 找规律、递推、归纳到一般项；
- 判断命题条件与结论；
- 由多个事实串联得出唯一结论。

不宜过度标`推理能力`的题：

- 只是定义直接套用，如分母不为 0；
- 只是按公式计算或化简；
- 只是识别一个图形或一个概念，没有形成条件到结论的链条。

初中边界：

- L1 常见于一步或两步直接推断；
- L2 常见于多步证明、复杂图形关系、递推规律；
- L3 应谨慎，通常需要较复杂的综合论证或高水平推理组织。

高中对应：

- 高中对应素养是`逻辑推理`，要求更强调演绎、归纳、类比的规范性，以及命题体系中的论证。

#### 2.1.6 数据观念

数据观念看的是：学生是否需要围绕数据进行收集、整理、表示、读取、分析、估计、推断或评价。

更容易标`数据观念`的题：

- 统计调查方式选择，全面调查与抽样调查；
- 条形图、扇形图、折线图、频数分布图的读取、补全和选择；
- 平均数、方差、中位数、众数等统计量解释；
- 根据样本估计总体；
- 根据统计图表作出数据判断。

不宜标`数据观念`的题：

- 只是有坐标图、函数图像、行程图像，但不是统计数据；
- 只是计算图中的数值，且不涉及数据背景、统计意义或随机性；
- 现实问题中出现一张表，但表格只是收费规则或数量关系模型，此时更可能是`模型观念`。

初中边界：

- 统计图表、调查、样本、总体、方差稳定优先考虑`数据观念`；
- 函数图像和统计图表要区分：前者多看`几何直观/模型观念`，后者多看`数据观念`。

高中对应：

- 高中对应素养是`数据分析`，更强调获取数据、整理数据、构建模型、统计推断和形成结论。

#### 2.1.7 模型观念

模型观念看的是：学生是否需要从现实或具体情境中建立方程、不等式、函数、分段关系、概率模型等数学模型，并用它解决问题。

更容易标`模型观念`的题：

- 行程、工程、收费、利润、积分、配水、电费、水费等实际关系建模；
- 分段函数、分段计费、规则转方程或函数；
- 古代数学应用题列方程组；
- 根据现实条件建立数量关系，再求解并解释。

不宜标`模型观念`的题：

- 已经给出函数解析式，只判断图像性质、增减性、交点或象限；
- 只是统计图表分析，主干是数据读取与估计；
- 只是代数运算或公式计算，没有从现实情境建立模型。

初中边界：

- 有现实情境不等于模型观念，必须看是否建立或使用数学模型；
- 建模题常伴随`运算能力`，但主素养看难点是否在“把现实关系组织成数学表达”。

高中对应：

- 高中对应素养是`数学建模`，要求更完整：发现问题、提出问题、建立模型、求解、检验、改进和解释。

#### 2.1.8 应用意识

应用意识看的是：学生是否需要有意识地用数学知识解释现实、评价现实方案、作出现实选择或解决现实任务。

更容易标`应用意识`的题：

- 根据数学结果比较现实方案，例如选择收费方案、路线方案、资源安排；
- 用数学解释现实规律、现象、风险、效率或公平性；
- 将计算或模型结果返回现实语境，判断是否合理、可行、满足约束；
- 题目主落点是“数学有什么用、如何用于现实判断”。

不宜标`应用意识`的题：

- 只有生活背景，但核心是计算、读图、证明、数据分析或建模；
- 题目只是把纯数学关系包装成购物、行程、活动、比赛等情境；
- 没有要求评价、解释、选择或现实意义判断。

初中边界：

- `应用意识`门槛要高于“有现实情境”；
- 若主任务是建立方程、函数或分段关系，优先考虑`模型观念`；
- 若主任务是读统计图和估计总体，优先考虑`数据观念`。

高中对应：

- 高中没有单列`应用意识`，其要求分散在`数学建模`、`数据分析`、`数学抽象`等素养中，尤其体现在把数学结果用于解释和解决现实问题。

#### 2.1.9 创新意识

创新意识看的是：学生是否需要主动发现问题、提出猜想、设计方案、开放探索或创造性地选择路径。

更容易标`创新意识`的题：

- 开放题、一题多解、方案设计；
- 先观察猜想再验证，且猜想不是唯一模板化结果；
- 要学生提出问题、改造条件、探索多种可能；
- 非常规实际问题或数学问题，路径不固定。

不宜标`创新意识`的题：

- 封闭式找规律，目标唯一、选项明确；
- 综合题、难题、辅助线题，但仍按标准逻辑推进；
- 只是“发现规律并求第 n 项”，若规律给得充分，通常更偏`推理能力`。

初中边界：

- `创新意识`应谨慎使用；
- 不要把“难”“综合”“找规律”自动等同于创新；
- 只有开放性、猜想生成、方案设计或非常规探索成为主任务时，才建议标注。

高中对应：

- 高中没有单列`创新意识`，相关要求主要体现在`数学建模`的模型改进、`数学抽象`的新命题形成、`逻辑推理`的猜想论证等更高水平表现中。

### 2.2 高中阶段六项素养的可操作边界

| 高中素养 | 更易分辨的定义 | 初中近似对应 | 最常见边界 |
| --- | --- | --- | --- |
| 数学抽象 | 从数量关系、图形关系或背景中提炼一般对象、结构、规律，并用数学语言表征 | 抽象能力 | 不是所有含字母的题都标抽象；若只是算式变形，更偏数学运算 |
| 逻辑推理 | 用演绎、归纳、类比等形式，从命题和条件推出新命题或结论 | 推理能力 | 公式套用不等于推理；证明、归纳、命题论证才更稳定 |
| 数学建模 | 面向现实问题建立、求解、检验和解释模型 | 模型观念、应用意识 | 有现实背景不等于建模；要看是否经历模型建立与解释 |
| 直观想象 | 借助图形、空间形式和形数联系理解数学对象及变化 | 几何直观、空间观念 | 仅有图不等于直观想象；图形结构必须推动理解或求解 |
| 数学运算 | 明确运算对象，选择方法，按规则完成运算、变形和求解 | 运算能力 | 若计算只是证明或建模的工具，通常作为次素养 |
| 数据分析 | 获取、整理、分析数据并进行统计推断，形成结论 | 数据观念 | 统计图是数据分析；函数图像通常不是数据分析 |

### 2.3 打标时的三步判断

1. 看题目主任务：题目到底让学生完成计算、证明、读图、建模、数据分析，还是现实决策？
2. 看解题主路径：真正推动解题的是算、推、看图、建关系、读数据，还是开放探索？
3. 看素养必要性：某素养如果只是背景元素或最后一步辅助，不作为主标；必要但非主导时可作为次标。

## 3. 初中阶段易混素养对比

### 3.1 抽象能力 vs 模型观念

| 项目 | 抽象能力 | 模型观念 |
| --- | --- | --- |
| 核心关注点 | 从具体情境中抽出变量、关系、规律、结构 | 用方程、不等式、函数等数学结构表达并解决现实问题 |
| 关键动作 | 把现实问题变成数学问题 | 把现实问题装入一个数学模型并跑通求解 |
| 典型表现 | 列出关系式、抽出变量、从具体到一般 | 建立方程模型、函数模型、分段关系模型，并解释结果 |
| 更像在做什么 | “抽出来” | “建起来并用起来” |
| 什么时候更偏它 | 难点在于从文字或情境中抽出关系 | 难点在于选择并建立合适的数学表达框架 |

快速判断：

- 重点在“识别数量关系” -> 更偏`抽象能力`
- 重点在“建立模型” -> 更偏`模型观念`

例子：

- “商品打折后价格如何表示” -> 更偏抽象能力
- “出租车收费如何写成分段函数” -> 更偏模型观念

真题提示：

- 八年级“博物馆参观”行程题：已知路程 10 千米、汽车速度是骑车速度的 2 倍、先后出发但同时到达，要求判断所列方程。  
  这类题虽然也有“设骑车速度为 x”的抽象过程，但题目的核心不止于抽出变量，而在于把现实中的路程、速度、时间关系组织成 `10/x - 10/2x = 1/3` 这样的数量关系模型，因此主素养更偏`模型观念`，`抽象能力`可作为伴随素养理解。

补充提醒：

- “写出第 n 个式子”或“根据前几项写出一般项”不宜机械地直接标为`抽象能力`。  
  如果题目的核心任务是从若干特例中归纳规律、推出一般表达，再完成后续推导，那么主干通常更偏`推理能力`。  
  只有当题目真正强调从具体对象中抽出数学对象、抽出变量关系、形成概念结构时，才更适合主标`抽象能力`。

- 关于数的概念辨析题，如倒数、相反数、绝对值、有理数/无理数判断等，如果核心任务是透过表示形式识别数学对象的本质属性，通常优先标`抽象能力`，而不是`推理能力`或`运算能力`。

V2 边界补充：

- `抽象能力`的重心是“提炼对象或结构”，不要求一定进入完整现实模型；
- `模型观念`的重心是“用模型表达并解决现实问题”，通常有方程、函数、不等式、分段规则等承载；
- 如果题目问“这个现实关系怎么表示”，且表示后要用来求解或解释，优先`模型观念`；
- 如果题目问“这个数学对象本质是什么”或“从具体中提炼一般结构”，优先`抽象能力`。

### 3.2 抽象能力 vs 应用意识

| 项目 | 抽象能力 | 应用意识 |
| --- | --- | --- |
| 核心关注点 | 从现实材料中提取数学关系 | 主动用数学解释现实、解决现实问题 |
| 关键动作 | 数学化 | 用数学 |
| 典型表现 | 把文字条件变成式子、关系、变量 | 用学过的知识判断方案、解释现象、处理实际问题 |
| 更像在做什么 | “把它变成数学” | “拿数学去处理它” |
| 什么时候更偏它 | 难点在于提取数学结构 | 难点在于把数学知识用到现实决策或现实解释中 |

快速判断：

- 重点在“抽关系” -> 更偏`抽象能力`
- 重点在“用数学解决现实问题” -> 更偏`应用意识`

真题提示：

- 上述“博物馆参观”行程题不宜主标`应用意识`。  
  原因不是它没有现实背景，而是它的关键难点不在“意识到数学能解决现实问题”，而在“如何把现实条件写成方程关系”。  
  因此这类题更适合主标`模型观念`，而不是`应用意识`。

V2 边界补充：

- `应用意识`要求题目落到现实解释、现实评价或现实决策；
- “现实背景 + 数学计算”通常不够；
- 如果学生只是把现实文字变成数学式子，优先看`抽象能力`或`模型观念`；
- 如果学生需要根据数学结果判断“哪种方案更合理”“结果在现实中是否可行”，再考虑`应用意识`。

### 3.3 推理能力 vs 运算能力

| 项目 | 推理能力 | 运算能力 |
| --- | --- | --- |
| 核心关注点 | 依据条件推出结论，形成论证链 | 依据法则和运算律进行正确、合理的运算 |
| 关键动作 | 说明“为什么成立” | 完成“怎么算出来” |
| 典型表现 | 证明、论证、从条件推出性质 | 化简、求值、解方程、计算概率 |
| 更像在做什么 | “往前推结论” | “把数和式算清楚” |
| 什么时候更偏它 | 计算只是工具，关键是论证 | 推理很少，主干靠计算推进 |

快速判断：

- 关键在“为什么成立” -> 更偏`推理能力`
- 关键在“如何算对、算快、算合理” -> 更偏`运算能力`

V2 边界补充：

- 定义直接套用不宜轻易标`推理能力`，例如分式有意义只需分母不为 0，主标`运算能力`即可；
- 公式识别和代数变形通常仍属于`运算能力`，例如整式运算、因式分解、根式化简；
- 若计算前需要由性质推出数量关系，如三角形内角和推出两个角的和，再联立角差，可加`推理能力 L1`；
- 若证明或规律归纳是主线，计算只是验证或收尾，则主标`推理能力`，运算作为次标或不标。

### 3.4 几何直观 vs 空间观念

| 项目 | 几何直观 | 空间观念 |
| --- | --- | --- |
| 核心关注点 | 借助图形、图表理解和分析问题 | 认识空间物体或图形的形状、大小、位置和变化 |
| 关键动作 | 用图帮助思考 | 对空间对象本身进行想象与表达 |
| 典型表现 | 画图、读图、借图找关系 | 判断方位、想象展开、描述旋转和平移后的关系 |
| 更像在做什么 | “借图分析” | “理解空间结构” |
| 什么时候更偏它 | 图是分析工具 | 空间对象本身是理解重点 |

快速判断：

- 重点在“借图想题” -> 更偏`几何直观`
- 重点在“想空间、想位置、想变化” -> 更偏`空间观念`

真题提示：

- 七年级方格纸作图题：  
  “在 6×6 方格中画一个面积为 6 的等腰三角形；在另一幅方格图中画一个与已知三角形全等且有一条公共边的三角形。”

  这类题容易被误标为`空间观念`，因为题目涉及格点位置和图形放置。  
  但更细看会发现，题目的核心任务是：

  - 借助方格图观察图形关系；
  - 根据图形条件直接构造三角形；
  - 利用图形和网格完成作图。

  所以主素养更偏`几何直观`。  
  如果题目进一步强调空间方位、展开折叠、旋转后的结构关系，才更明显地向`空间观念`靠近。

V2 边界补充：

- 平面几何图、坐标图、函数图像、统计图都不自动等于`空间观念`；
- 平面内借图找关系，优先`几何直观`；
- 立体图形、展开折叠、三视图、空间方位和三维想象，才优先`空间观念`；
- 只有几何知识没有图形分析，如三角形三边关系、内角和计算，不宜标`几何直观`。

### 3.5 数据观念 vs 模型观念

| 项目 | 数据观念 | 模型观念 |
| --- | --- | --- |
| 核心关注点 | 数据的收集、整理、分析和解释 | 用数学结构表达现实问题 |
| 关键动作 | 看数据、解释数据、根据数据判断 | 建立数量关系模型、变化规律模型 |
| 典型表现 | 统计图表分析、趋势判断、概率解释 | 方程、不等式、函数、分段关系的建立 |
| 更像在做什么 | “让数据说话” | “让关系成型” |
| 什么时候更偏它 | 题目主干在数据分析与判断 | 题目主干在数学化建模 |

快速判断：

- 重点在“数据告诉了我们什么” -> 更偏`数据观念`
- 重点在“这个现实问题该用什么数学结构表示” -> 更偏`模型观念`

V2 边界补充：

- 统计调查、样本总体、平均数、方差、扇形图、条形图、折线图选择，优先`数据观念`；
- 阶梯水价、足球积分、古代方程组、行程数量关系，优先`模型观念`；
- 表格不一定是数据观念：如果表格给的是规则、收费标准、函数关系，通常更偏`模型观念`；
- 图像不一定是数据观念：函数图像、距离-时间图像主要看`几何直观`或`模型观念`，不是统计数据分析。

### 3.6 模型观念 vs 应用意识

| 项目 | 模型观念 | 应用意识 |
| --- | --- | --- |
| 核心关注点 | 用数学模型描述和解决现实问题 | 主动把数学用于现实解释和现实解决 |
| 关键动作 | 建模 | 应用 |
| 典型表现 | 写出方程、函数、不等式模型并解释结果 | 比较方案、解释现象、解决实际任务 |
| 更像在做什么 | “怎么建框架” | “为什么要把数学用上” |
| 什么时候更偏它 | 难点在模型建立 | 难点在现实应用判断 |

快速判断：

- 重点在“怎么写出模型” -> 更偏`模型观念`
- 重点在“怎么把数学用于现实决策” -> 更偏`应用意识`

应用意识的判定门槛：

`应用意识`不是“题目有现实背景”就标，而是题目的主要任务要落在把数学知识用于现实解释、现实评价或现实决策上。  
如果现实背景只是数据、方程、比例、统计图、函数关系的载体，而解题主干明显是读数据、建模型、算结果或证明关系，则应优先标对应的主素养，而不是直接标`应用意识`。

更适合标`应用意识`的情况通常包括：

- 要学生根据数学结果对现实方案作出选择，例如比较两种收费、促销、路线或资源配置方案哪一个更合理；
- 要学生解释现实情境中的现象或规律，例如用数学知识说明某种变化趋势、风险、效率或公平性；
- 要学生把数学结论返回现实语境中评价其意义，例如结果是否合理、是否可行、是否满足现实约束；
- 题目重点不在建立复杂模型或处理数据本身，而在“如何用数学服务现实判断”。

不宜标`应用意识`的常见情况包括：

- 只是给统计调查、生活购物、行程、工程等现实背景，但核心任务是计算、读图、建方程或补全数据；
- 题目最后有一句现实化问法，但整个解题主干仍是统计图分析、比例估计或公式运算；
- 现实语境只负责包装题目，没有要求学生对现实问题作出评价、解释或决策。

真题提示：

- “博物馆参观”行程题再次说明：  
  只要一道题的主要难点是“如何把现实条件组织成方程、函数或其他数量关系模型”，就应优先考虑`模型观念`。  
  只有当题目主要落点在“利用数学知识评价现实方案、解释现实现象、作出现实判断”时，才更适合主标`应用意识`。

补充提醒：

- 只要出现函数，不自动等于`模型观念`。  
  如果题目只是直接给出函数解析式，让学生判断图像位置、增减性、象限、交点等性质，而没有“从现实情境建立函数关系”的过程，那么通常不宜标`模型观念`。

V2 边界补充：

- `模型观念`解决“现实关系如何数学化表达”的问题；
- `应用意识`解决“数学结果如何服务现实判断”的问题；
- 一道题可以同时有模型和应用，但只有当结果需要回到现实中评价、选择或解释时，才把`应用意识`作为稳定标注；
- 多数初中应用题的主素养应先在`模型观念`、`运算能力`、`数据观念`中寻找，最后再判断是否真的需要`应用意识`。

### 3.7 推理能力 vs 创新意识

| 项目 | 推理能力 | 创新意识 |
| --- | --- | --- |
| 核心关注点 | 在已有规则下推出结论 | 主动发现问题、提出猜想、探索新路径 |
| 关键动作 | 论证 | 探索 |
| 典型表现 | 证明题、条件推结论 | 规律探究题、开放题、猜想验证题 |
| 更像在做什么 | “把它证明出来” | “把它想出来” |
| 什么时候更偏它 | 题目路径较明确 | 题目允许多路径、开放探索或自主构造 |

快速判断：

- 重点在“按逻辑推出结论” -> 更偏`推理能力`
- 重点在“提出新想法或猜想” -> 更偏`创新意识`

使用提醒：

创新意识要谨慎使用，不能因为题目综合、辅助线多、解题难，就直接标为`创新意识`。  
下列类型更适合优先考虑`创新意识`：

- 先猜想再证明
- 一题多解
- 规律探究
- 开放构造
- 明显鼓励自主方案设计

如果题目仍然是封闭题，且核心任务主要是依据已知条件持续推出结论、完成论证，那么通常仍应优先标为`推理能力`，而不是`创新意识`。

补充提醒：

- “找规律”不自动等于`创新意识`。  
  如果题目只是要求根据给出的若干例子识别规律、写出一般项、完成计算，且目标唯一、路线较标准，那么通常更偏`推理能力`。  
  只有当题目明显鼓励自主猜想、开放探究、多路径生成时，才更考虑`创新意识`。

- 命题改写题、条件结论识别题、把文字命题改写成“如果……那么……”形式的题，通常优先标`推理能力`。  
  这类题的核心在于理解命题结构、区分条件和结论、完成规范表达，而不是进行数量抽象。

V2 边界补充：

- 找规律题在 50 道样例中多数应落到`推理能力`，不是`创新意识`；
- 只有封闭目标、固定选项、标准递推或归纳的规律题，通常不标`创新意识`；
- 难题不等于创新题，综合题不等于创新题；
- 需要学生自主提出猜想、设计方案、改变条件、开放构造或多解探索时，才更适合标`创新意识`。

### 3.8 几何直观 vs 推理能力

| 项目 | 几何直观 | 推理能力 |
| --- | --- | --- |
| 核心关注点 | 借图发现或理解关系 | 依据条件和定理推出结论 |
| 关键动作 | 看出关系 | 证明关系 |
| 典型表现 | 读图、图像上下、角的位置、格点结构 | 平行判定、全等相似证明、递推论证 |
| 更像在做什么 | “图告诉我怎么想” | “条件推出什么结论” |
| 什么时候更偏它 | 图形结构是入口和主路径 | 逻辑链条是主路径 |

快速判断：

- 图像解不等式、坐标路径规律、格点相似识别 -> 常以`几何直观`为主；
- 平行线判定证明、菱形角相等证明、由条件推出结论 -> 常以`推理能力`为主；
- 若既要读图又要多步论证，可双标，但要分主次。

V2 边界补充：

- “有图”不自动标`几何直观 L2`；
- 只是在图中定位角或边，通常`几何直观 L1`；
- 图形结构复杂并决定解法，才考虑`几何直观 L2`；
- 证明链长、条件转换多、需要补全理由，才考虑`推理能力 L2`或以上。

### 3.9 几何直观 vs 运算能力

| 项目 | 几何直观 | 运算能力 |
| --- | --- | --- |
| 核心关注点 | 通过图形或图像确定关系 | 通过计算得到结果 |
| 关键动作 | 读图、识图、形数结合 | 代入、化简、求值、计算 |
| 典型表现 | 函数图像解不等式、坐标图判断、面积结构观察 | 角度计算、面积公式、代数式化简 |
| 更像在做什么 | “先看懂结构” | “把结果算出来” |
| 什么时候更偏它 | 不看图就无法确定关系 | 不需要复杂图形关系，直接算即可 |

快速判断：

- 交点、上下关系、格点结构、坐标图形位置 -> 优先`几何直观`；
- 已知公式或条件直接求数值 -> 优先`运算能力`。

V2 边界补充：

- 菱形对角线求面积这类直接公式题，主标`运算能力`，不因“菱形”自动标`几何直观`；
- 点到坐标轴距离、分式有意义、根式有意义等直接规则题，主标`运算能力`；
- 如果图形关系只是帮助理解题意，计算才是主路径，几何直观可不标或仅作 L1。

### 3.10 数据观念 vs 运算能力

| 项目 | 数据观念 | 运算能力 |
| --- | --- | --- |
| 核心关注点 | 数据代表什么，如何收集、整理、解释和推断 | 数值如何计算正确 |
| 关键动作 | 读数据、析数据、估总体、判调查 | 算比例、求平均、算角度、算人数 |
| 典型表现 | 调查方式、统计图选择、方差稳定性、样本估计 | 根据图表做基础加减乘除 |
| 更像在做什么 | “用数据说明问题” | “把数算出来” |
| 什么时候更偏它 | 统计意义是主干 | 统计背景只是计算材料 |

快速判断：

- 问“适合哪种调查”“哪种统计图合适”“谁更稳定”“样本估计总体” -> 优先`数据观念`；
- 只是在统计图中读数后做简单加减乘除，可把`运算能力`作为次素养。

V2 边界补充：

- 统计图补全和总体估计，通常`数据观念 L2`，运算视复杂度加 L1 或 L2；
- 平均数、方差用于选择稳定对象，主标`数据观念`，不只是计算；
- 若没有数据的统计意义，只是图表中的规则计算，不宜标`数据观念`。

## 4. 高中阶段易混素养对比

### 4.1 数学抽象 vs 数学建模

| 项目 | 数学抽象 | 数学建模 |
| --- | --- | --- |
| 核心关注点 | 从具体背景中抽出概念、关系和结构 | 用数学语言和模型表达并解决现实问题 |
| 关键动作 | 抽象出数学对象 | 建立并求解模型 |
| 更像在做什么 | “把对象提炼出来” | “把问题建成模型并解决” |

快速判断：

- 重点在概念化、结构化 -> `数学抽象`
- 重点在现实问题建模求解 -> `数学建模`

补充提醒：

- 函数综合题不自动等于`数学建模`。  
  如果题目没有“从现实情境建立函数关系”的过程，而只是直接给出函数、图像、坐标关系，要求判断性质、求解析式、求最值、求交点等，那么通常不宜因为“有函数”就直接标为`数学建模`。

### 4.2 逻辑推理 vs 数学运算

| 项目 | 逻辑推理 | 数学运算 |
| --- | --- | --- |
| 核心关注点 | 依据规则推出结论 | 依据法则完成运算求解 |
| 关键动作 | 论证与推出 | 变形与求值 |
| 更像在做什么 | “证明它” | “算出它” |

快速判断：

- 关键在证明、推出、说明 -> `逻辑推理`
- 关键在运算流程和结果 -> `数学运算`

### 4.3 直观想象 vs 数学抽象

| 项目 | 直观想象 | 数学抽象 |
| --- | --- | --- |
| 核心关注点 | 借助图形和空间形式理解问题 | 从关系中抽象出概念和结构 |
| 关键动作 | 图形化、形象化 | 概念化、结构化 |
| 更像在做什么 | “先看见它” | “再提炼它” |

快速判断：

- 重点在借图、借形、借空间关系理解 -> `直观想象`
- 重点在形成一般关系和概念 -> `数学抽象`

### 4.4 数学建模 vs 数据分析

| 项目 | 数学建模 | 数据分析 |
| --- | --- | --- |
| 核心关注点 | 建立模型表达现实问题 | 获取、整理、分析、推断数据 |
| 关键动作 | 建关系 | 看数据 |
| 更像在做什么 | “搭框架” | “做判断” |

快速判断：

- 若核心是建立函数、方程、优化模型 -> `数学建模`
- 若核心是从数据中提取信息并作推断 -> `数据分析`

## 5. 当前版本的几个总原则

### 5.1 原则一：先看核心任务

不要先看题目外观，要先看题目最核心要求学生做什么。

### 5.2 原则二：先分主次，再谈并列

如果一道题明显涉及多个素养，优先先找主素养，再补次素养。

### 5.3 原则三：不要因为“出现了某种元素”就直接贴标签

例如：

- 有图，不一定主素养就是几何直观或直观想象；
- 有情境，不一定主素养就是模型观念或数学建模；
- 有计算，不一定主素养就是运算能力或数学运算；
- 有现实背景，不一定主素养就是应用意识。

结合前面两道真题，可以再补两条很实用的提醒：

- 有方格图和作图要求，不一定就是空间观念，很多时候只是`几何直观`；
- 有生活情境和速度时间路程，不一定就是应用意识，很多时候核心其实是`模型观念`。
- 有调查、统计图和总体估计，也不一定就是应用意识；如果核心是“数据怎么读、怎么补、怎么估”，应优先标`数据观念`。

建议综合两位标注员意见，以`几何直观 L2`为主，保留`推理能力 L1`，不标`运算能力`。

分析思路：

不等式：

```text
kx + n >= ax^2 + bx + c
```

表示一次函数图像在二次函数图像的上方或重合。  
从图像可见，直线与抛物线在 `x = -1` 和 `x = 9` 处相交，在两个交点之间直线位于抛物线上方，因此解集为：

```text
-1 <= x <= 9
```

因此答案为 A。

为什么标`几何直观 L2`：

题目核心不是计算函数解析式或代数求解不等式，而是把不等式 `y1 >= y2` 转化为“直线在抛物线上方或重合”的图像位置关系。  
学生需要根据两个交点和两条图像的上下关系确定区间，图像判断是解题主路径，因此应标`几何直观 L2`。

为什么标`推理能力 L1`：

学生需要完成“函数值大小关系 -> 图像上下关系 -> 对应 x 的取值区间”的简单推断。  
推理链较短，依附于图像观察，因此标`推理能力 L1`即可。

为什么不标`运算能力`：

题目不要求求出 `k、n、a、b、c`，也不需要进行代数化简、方程求解或复杂计算。  
交点横坐标已经给出，关键是图像区间判断，所以不宜把`运算能力`作为本题素养。

### 6.46 例子四十六：平行线判定条件选择

题目ID：**28248**

完整题目：

如图，点 E 在 AC 的延长线上，下列条件中能判断 `AB ∥ CD` 的是（ ）。

A. `∠D = ∠DCE`  
B. `∠3 = ∠4`  
C. `∠1 = ∠2`  
D. `∠A + ∠ABD = 180°`

推荐标注：

```json
{
  "学段": "初中",
  "题型": "选择",
  "素养标注": [
    {
      "素养": "推理能力",
      "水平": "L1"
    },
    {
      "素养": "几何直观",
      "水平": "L1"
    }
  ]
}
```

两位标注员的分歧点：

- 标注员 1：`运算能力 L1`、`几何直观 L2`、`推理能力 L2`
- 标注员 2：`几何直观 L1`、`推理能力 L1`

推荐采用标注员 2 的方向。

分析思路：

要判断 `AB ∥ CD`，应寻找以 `BC` 为截线时，`AB` 与 `CD` 形成的内错角或同位角关系。  
图中 `∠1` 是 `AB` 与 `BC` 所成的角，`∠2` 是 `BC` 与 `CD` 所成的角，若 `∠1 = ∠2`，则可由内错角相等判定：

```text
AB ∥ CD
```

因此答案为 C。

其他选项的指向：

- `∠D = ∠DCE` 更容易指向 `BD ∥ CE`；
- `∠3 = ∠4` 更容易指向 `AC ∥ BD`；
- `∠A + ∠ABD = 180°` 也是以 `AB` 为截线判断 `AC ∥ BD`。

为什么标`推理能力 L1`：

学生需要根据角相等或角互补条件，判断它们能推出哪一组直线平行。  
这是平行线判定定理的直接应用，推理链较短，因此标`推理能力 L1`。

为什么标`几何直观 L1`：

题目需要在图中识别角的位置、截线以及被截直线，图形信息是必要的。  
但不需要复杂构造、图形变换或多步图形关系分析，因此给 `L1` 即可。

为什么不标`运算能力`：

题目没有数值计算，也没有代数运算。  
“`180°`”只是平行线判定中的角互补条件，不构成本题的运算核心。

### 6.47 例子四十七：三角形内角和与角差求角

题目ID：**34135**

完整题目：

在 `△ABC` 中，`∠A = 105°`，`∠B - ∠C = 15°`，则 `∠C` 的度数为（ ）。

A. `35°`  
B. `60°`  
C. `45°`  
D. `30°`

推荐标注：

```json
{
  "学段": "初中",
  "题型": "选择",
  "素养标注": [
    {
      "素养": "运算能力",
      "水平": "L1"
    },
    {
      "素养": "推理能力",
      "水平": "L1"
    }
  ]
}
```

两位标注员的分歧点：

- 标注员 1：`运算能力 L1`
- 标注员 2：`运算能力 L1`、`推理能力 L1`

推荐采用标注员 2 的方向。

分析思路：

由三角形内角和可得：

```text
∠B + ∠C = 180° - 105° = 75°
```

又已知：

```text
∠B - ∠C = 15°
```

两式相减或联立可得：

```text
2∠C = 60°
∠C = 30°
```

因此答案为 D。

为什么标`运算能力 L1`：

题目需要进行角度加减、简单方程或等量关系运算。  
计算过程基础，难度较低，因此标`运算能力 L1`。

为什么标`推理能力 L1`：

学生需要先由三角形内角和推出 `∠B + ∠C = 75°`，再结合 `∠B - ∠C = 15°` 得到 `∠C`。  
这里不仅是直接算式代入，还包含从几何性质到数量关系的简单推断，因此可标`推理能力 L1`。

为什么不标`几何直观`：

题目没有给图，也不需要通过图形位置、角的可视化关系或辅助线来发现结论。  
它使用的是三角形内角和的数量关系，不宜因为出现三角形就标`几何直观`。

### 6.48 例子四十八：分式有意义的取值范围

题目ID：**34617**

完整题目：

若分式 `2/(x - 2)` 有意义，则 `x` 的取值范围是（ ）。

A. `x ≠ -2`  
B. `x ≠ 2`  
C. `x ≥ -2`  
D. `x ≥ 2`

推荐标注：

```json
{
  "学段": "初中",
  "题型": "选择",
  "素养标注": [
    {
      "素养": "运算能力",
      "水平": "L1"
    }
  ]
}
```

两位标注员的分歧点：

- 标注员 1：`推理能力 L1`
- 标注员 2：`运算能力 L1`

推荐采用标注员 2 的方向。

分析思路：

分式有意义要求分母不为 `0`：

```text
x - 2 ≠ 0
```

所以：

```text
x ≠ 2
```

因此答案为 B。

为什么标`运算能力 L1`：

题目核心是根据分式有意义的条件，完成一个最基础的一次式不等于零的求解。  
虽然计算很简单，但本质仍是代数式条件处理，因此标`运算能力 L1`。

为什么不标`推理能力`：

“分母不为 0”是分式有意义的直接定义条件，本题没有形成多步逻辑判断、性质串联或结论论证。  
若把这类定义直接套用都标为`推理能力`，会导致推理能力边界过宽。

### 6.49 例子四十九：整式运算与因式分解

题目ID：**34875**

完整题目：

计算：

```text
(2y)^2 · (-xy^2)
```

分解因式：

```text
ax^2 + 2a^2x + a^3
```

推荐标注：

```json
{
  "学段": "初中",
  "题型": "解答",
  "素养标注": [
    {
      "素养": "运算能力",
      "水平": "L2"
    }
  ]
}
```

两位标注员的分歧点：

- 标注员 1：`运算能力 L2`
- 标注员 2：`运算能力 L2`、`推理能力 L1`

推荐采用标注员 1 的方向，只标`运算能力 L2`。

分析思路：

第一问：

```text
(2y)^2 · (-xy^2)
= 4y^2 · (-xy^2)
= -4xy^4
```

第二问：

```text
ax^2 + 2a^2x + a^3
= a(x^2 + 2ax + a^2)
= a(x + a)^2
```

为什么标`运算能力 L2`：

题目包含幂的运算、单项式乘法、提公因式、完全平方公式识别与因式分解。  
它不是单一步骤计算，而是多个代数运算规则的组合使用，因此比基础直接计算更适合标`运算能力 L2`。

为什么不标`推理能力`：

因式分解中确实需要识别结构，但这种识别主要服务于公式运算，不形成独立的条件推断、证明链或规律论证。  
若只是选择合适的运算法则或公式，一般归入`运算能力`，不额外标`推理能力`。

### 6.50 例子五十：坐标系中等边三角形递推规律

题目ID：**34887**

完整题目：

如图，在平面直角坐标系中，`O` 为坐标原点，点 `N` 在 `x` 轴正半轴上，点 `A1，A2，A3，...` 在射线 `ON` 上，点 `B1，B2，B3，...` 在射线 `OM` 上，`∠MON = 30°`，`△A1B1A2`，`△A2B2A3`，`△A3B3A4`，... 均为等边三角形，依此类推。若 `OA1 = 1`，则点 `B2020` 的横坐标是（ ）。

推荐标注：

```json
{
  "学段": "初中",
  "题型": "选择",
  "素养标注": [
    {
      "素养": "几何直观",
      "水平": "L2"
    },
    {
      "素养": "推理能力",
      "水平": "L2"
    },
    {
      "素养": "运算能力",
      "水平": "L1"
    }
  ]
}
```

两位标注员的分歧点：

- 标注员 1：`运算能力 L1`、`几何直观 L2`、`推理能力 L2`
- 标注员 2：`几何直观 L1`、`推理能力 L2`、`创新意识 L1`

推荐采用标注员 1 的方向。

分析思路：

设 `A_n` 的横坐标为 `x_n`，则 `A_{n+1}` 的横坐标为 `x_{n+1}`。  
因为 `△A_nB_nA_{n+1}` 是等边三角形，且 `A_n、A_{n+1}` 在 `x` 轴上，所以：

```text
B_n 的横坐标 = (x_n + x_{n+1})/2
B_n 的纵坐标 = (√3/2)(x_{n+1} - x_n)
```

又因为 `B_n` 在与 `x` 轴夹角为 `30°` 的射线 `OM` 上，所以：

```text
B_n 的纵坐标 / B_n 的横坐标 = tan30° = 1/√3
```

代入可得：

```text
[(√3/2)(x_{n+1} - x_n)] / [(x_n + x_{n+1})/2] = 1/√3
```

整理得：

```text
x_{n+1} = 2x_n
```

又 `x_1 = OA1 = 1`，所以：

```text
x_n = 2^(n-1)
```

点 `B_n` 的横坐标为：

```text
(x_n + x_{n+1})/2 = (2^(n-1) + 2^n)/2 = 3 · 2^(n-2)
```

因此 `B2020` 的横坐标为：

```text
3 · 2^2018
```

为什么标`几何直观 L2`：

题目必须读懂坐标轴、射线 `OM`、等边三角形顶点位置之间的结构关系。  
学生需要把“点在 30° 射线上”和“等边三角形顶点在底边中点正上方”结合起来，形成几何位置关系，因此图形理解不是辅助信息，而是解题主路径，适合标`几何直观 L2`。

为什么标`推理能力 L2`：

题目不是只判断一个静态图形，而是要从第 `n` 个等边三角形推出 `A_n` 与 `A_{n+1}` 的递推关系，再推广到 `B2020`。  
其中包含“结构关系 -> 递推关系 -> 一般项 -> 指定项”的多步推断，因此标`推理能力 L2`。

为什么标`运算能力 L1`：

题目需要进行简单的坐标表达、比例整理和指数形式计算。  
这些运算服务于几何结构和规律推导，难度不高，因此作为次素养标`运算能力 L1`即可。

为什么不标`创新意识`：

题目虽然要发现规律，但目标、图形结构和结论形式都很明确，属于封闭式规律推断。  
学生不需要提出新问题、设计新方案或开放探索多种路径，因此不宜标`创新意识`。

## 7. V2 版本的使用建议

当前 V2 适合用于：

- 标注员培训中的口径统一；
- 复核存在分歧的题目；
- 判断主素养与次素养；
- 将官方定义转化为更容易执行的题目打标规则。

后续如果继续迭代 V3，方向包括：

1. 将 50 道样例继续扩展为按素养分类的题库；
2. 对每个素养建立 L1、L2、L3 的水平判定细则；
3. 增加高中阶段的实题样例；
4. 将“题目主任务 -> 解题主路径 -> 推荐素养”的流程做成标注决策树。
