# UI 设计文档

## 1. 设计原则

- **清晰性**：标注界面突出题干，减少认知负荷
- **效率性**：一键推荐、快速标注、批量操作
- **反馈性**：实时保存、进度可见、状态明确
- **协作性**：多人标注状态一目了然，避免冲突

**关键交互说明**：
- 左侧面板显示试题列表，每个试题显示当前标注进度（如 `1/3`）
- `[推荐]` 标签的试题是 Coreset 算法推荐的高价值试题
- 右侧面板中，每个素养维度有 4 个单选按钮（0-3级），可多选（一道题可含多个素养）
- 提交后自动加载下一道推荐试题
- 底部显示其他标注员的标注结果（匿名），帮助用户判断一致性

**其他推荐可视化方法**：

| 可视化方法 | 适用场景 | 优点 |
|-----------|---------|------|
| **t-SNE** | 局部结构展示 | 保持局部邻域关系，适合观察聚类 |
| **UMAP** | 全局+局部结构 | 计算更快，保留更多全局结构 |
| **PCA** | 快速概览 | 计算极快，可解释性强（主成分） |
| **Heatmap (相似度矩阵)** | 试题间关系 | 直观显示哪些试题语义相近 |
| **雷达图** | 单题多素养分布 | 展示一道题在各素养维度的覆盖情况 |
| **桑基图 / Alluvial** | 标注流转 | 显示标注状态流转（待标→标注中→完成） |
| **箱线图** | 标注一致性分析 | 展示不同标注员间的 IAA 分布 |
| **主动学习曲线** | 实验效果对比 | 横轴为样本数，纵轴为 F1，对比不同 Coreset 策略 |

|-------|------|---------|------|
| `QuestionCard` | 列表/推荐 | 多 | 试题卡片，显示题干摘要、状态、进度 |
| `CompetencySelector` | 标注页 | 1 | 9维度×4层级的单选矩阵 |
| `CoresetBadge` | 列表/可视化 | 多 | 显示"[推荐]"标签和算法名 |
| `ProgressRing` | 各处 | 多 | 环形进度条，显示标注完成度 |
| `ScatterPlot` | 可视化页 | 1 | 可交互的 2D 散点图（基于 ECharts/Plotly）|
| `TrainingCurve` | 训练页 | 1 | 主动学习折线图 |
| `AnnotationHistory` | 标注页 | 1 | 显示该题的历史标注记录 |

## 5. 响应式断点

| 设备 | 宽度 | 布局调整 |
|-----|------|---------|
| 桌面端 | ≥1280px | 左右分栏（列表+标注区） |
| 平板端 | 768-1279px | 列表可折叠，标注区为主 |
| 移动端 | <768px | 单栏，底部Tab切换列表和标注 |

> **说明**：标注工作主要在桌面端完成，移动端仅支持查看和简单标注。
