## 2. 详细表结构

### 2.1 用户表 `users`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | UUID / BIGINT | PK, auto | 用户唯一标识 |
| `username` | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| `email` | VARCHAR(255) | UNIQUE, NOT NULL | 邮箱 |
| `hashed_password` | VARCHAR(255) | NOT NULL | 加密密码 |
| `role_id` | BIGINT | FK → roles.id | 角色 |
| `is_active` | BOOLEAN | DEFAULT TRUE | 是否激活 |
| `is_verified` | BOOLEAN | DEFAULT FALSE | 是否通过培训 |
| `created_at` | TIMESTAMP | DEFAULT now() | 注册时间 |
| `last_login` | TIMESTAMP | NULL | 最后登录 |

### 2.2 角色表 `roles`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | BIGINT | PK, auto | 角色ID |
| `name` | VARCHAR(50) | UNIQUE | admin / annotator / viewer |
| `permissions` | JSONB | | 权限列表 |

### 2.3 试题表 `questions`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | UUID / BIGINT | PK, auto | 试题唯一标识 |
| `item_id` | VARCHAR(64) | UNIQUE, NOT NULL | 业务ID (如 single_choice_0001) |
| `subject` | VARCHAR(20) | DEFAULT 'math' | 学科 |
| `grade_name` | VARCHAR(20) | | 年级 (七年级/八年级/九年级) |
| `grade_index` | SMALLINT | | 年级编码 (7/8/9) |
| `edu_stage` | VARCHAR(10) | | 学段编码 |
| `item_type` | VARCHAR(30) | | single_choice / fill_blank /解答题 等 |
| `difficulty` | SMALLINT | | 难度 (1-5) |
| `cognitive_level_text` | VARCHAR(20) | | 认知层级文本 |
| `question_text` | TEXT | NOT NULL | 题干文本 (含 LaTeX) |
| `options` | JSONB | | 选项列表 |
| `answer` | TEXT | | 答案 |
| `solution` | TEXT | | 解析 |
| `has_sub_questions` | BOOLEAN | DEFAULT FALSE | 是否有子题 |
| `total_score` | NUMERIC(5,2) | | 总分 |
| `knowledge_points` | JSONB | | 知识点列表 [{id, name, weight}] |
| `item_tags` | JSONB | | 标签 [{name}] |
| `status` | VARCHAR(20) | DEFAULT 'PENDING' | PENDING / ANNOTATING / COMPLETED |
| `annotation_count` | SMALLINT | DEFAULT 0 | 已被几人标注 |
| `required_annotations` | SMALLINT | DEFAULT 3 | 需要几人标注 (默认3) |
| `created_at` | TIMESTAMP | DEFAULT now() | 入库时间 |
| `updated_at` | TIMESTAMP | DEFAULT now() | 更新时间 |
| `source` | VARCHAR(50) | | 数据来源 (已标注集/未标注集) |

> **状态流转**：
> ```
> PENDING ──► ANNOTATING (首次被标注) ──► COMPLETED (count >= 3 且 annotator 数 >= 3)
>                    ▲                          │
>                    └──────────────────────────┘ (若出现争议，可回退)
> ```

### 2.4 标注记录表 `annotations`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | UUID / BIGINT | PK, auto | 标注记录ID |
| `question_id` | BIGINT | FK → questions.id, NOT NULL | 试题 |
| `user_id` | BIGINT | FK → users.id, NOT NULL | 标注员 |
| `version` | SMALLINT | DEFAULT 1 | 标注版本 (支持修改) |
| `competencies` | JSONB | NOT NULL | 素养标注 [{competency_id, level}] |
| `cognitive_level` | SMALLINT | NULL | 认知层级 (0-5) |
| `knowledge_points` | JSONB | NULL | 知识点标注 [{kp_id, name}] |
| `confidence` | SMALLINT | NULL | 标注员自信度 (1-5) |
| `time_spent_seconds` | INT | | 标注耗时 |
| `is_final` | BOOLEAN | DEFAULT FALSE | 是否最终版 |
| `created_at` | TIMESTAMP | DEFAULT now() | 提交时间 |
| `updated_at` | TIMESTAMP | DEFAULT now() | 更新时间 |

> **唯一约束**：`(question_id, user_id, version)` — 同一用户对同一题可有多版本

### 2.5 素养标签聚合表 `question_competency_labels`（预计算/缓存）
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | BIGINT | PK | |
| `question_id` | BIGINT | FK → questions.id | |
| `competency_id` | SMALLINT | NOT NULL | 0-8 (9大素养) |
| `level` | SMALLINT | NOT NULL | 0-3 (聚合后层级) |
| `agreement_score` | NUMERIC(3,2) | | 标注一致性分数 |
| `is_disputed` | BOOLEAN | DEFAULT FALSE | 是否存在争议 |
| `annotation_ids` | BIGINT[] | | 参与聚合的标注记录ID |

### 2.6 试题嵌入表 `question_embeddings`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | BIGINT | PK | |
| `question_id` | BIGINT | FK → questions.id, UNIQUE | |
| `model_name` | VARCHAR(100) | NOT NULL | 模型标识 (如 roberta-wwm-ext) |
| `embedding` | vector(768) / JSONB / BYTEA | NOT NULL | 嵌入向量 (pgvector 或存 JSON) |
| `dimension` | SMALLINT | DEFAULT 768 | 维度 |
| `computed_at` | TIMESTAMP | DEFAULT now() | 计算时间 |

> 建议使用 PostgreSQL + `pgvector` 扩展以支持高效的向量检索和相似度计算。

### 2.7 Coreset 推荐记录表 `recommendations`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | BIGINT | PK | |
| `algorithm` | VARCHAR(50) | NOT NULL | 使用的 Coreset 算法名 |
| `question_id` | BIGINT | FK → questions.id | 被推荐的试题 |
| `score` | NUMERIC(10,6) | | 推荐分数 (越高越优先) |
| `rank` | INT | | 推荐排名 |
| `batch_id` | VARCHAR(64) | | 本次推荐批次号 |
| `context` | JSONB | | 上下文 (当前已标注数、模型版本等) |
| `is_accepted` | BOOLEAN | NULL | 是否被用户采纳标注 |
| `created_at` | TIMESTAMP | DEFAULT now() | |

### 2.8 Coreset 实验日志表 `coreset_logs`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | BIGINT | PK | |
| `algorithm` | VARCHAR(50) | NOT NULL | |
| `batch_id` | VARCHAR(64) | NOT NULL | |
| `params` | JSONB | | 算法超参数 |
| `metrics` | JSONB | | 评估指标 (CoverageRadius, AMS, Redundancy, CRR, PCA_ratio, MMD) |
| `selected_question_ids` | BIGINT[] | | 选中的试题ID列表 |
| `computed_at` | TIMESTAMP | DEFAULT now() | |

### 2.9 模型训练任务表 `training_tasks`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | BIGINT | PK | |
| `task_name` | VARCHAR(100) | | 任务名 |
| `model_type` | VARCHAR(50) | | 模型类型 (EduCompetencyModel) |
| `base_model` | VARCHAR(100) | | hfl/chinese-roberta-wwm-ext |
| `dataset_config` | JSONB | | 训练/验证/测试集配置 |
| `hyperparams` | JSONB | | 超参数 |
| `status` | VARCHAR(20) | DEFAULT 'PENDING' | PENDING / RUNNING / SUCCESS / FAILED |
| `metrics` | JSONB | NULL | 评估结果 (F1, 等级准确率, 素养检出率) |
| `model_path` | VARCHAR(255) | NULL | 模型权重存储路径 |
| `celery_task_id` | VARCHAR(100) | NULL | Celery 任务ID |
| `started_at` | TIMESTAMP | NULL | |
| `finished_at` | TIMESTAMP | NULL | |
| `created_by` | BIGINT | FK → users.id | |

### 2.10 学习记录表 `learning_records`
| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| `id` | BIGINT | PK | |
| `user_id` | BIGINT | FK → users.id | |
| `module` | VARCHAR(50) | | 学习模块 (标注指南 / 示例练习) |
| `progress_percent` | NUMERIC(5,2) | | 完成百分比 |
| `is_completed` | BOOLEAN | DEFAULT FALSE | 是否完成 |
| `completed_at` | TIMESTAMP | NULL | |

## 3. 关系说明

| 关系 | 类型 | 说明 |
|-----|------|------|
| `users` ↔ `roles` | N:1 | 用户属于一个角色 |
| `users` ↔ `annotations` | 1:N | 用户提交多条标注 |
| `questions` ↔ `annotations` | 1:N | 试题有多条标注记录 |
| `questions` ↔ `question_embeddings` | 1:1 | 每道题对应一个版本的嵌入 |
| `questions` ↔ `question_competency_labels` | 1:N | 一道题有多个素养标签 (聚合后) |
| `questions` ↔ `recommendations` | 1:N | 一道题可被多次推荐 |
| `users` ↔ `learning_records` | 1:N | 用户有多个学习模块记录 |
| `training_tasks` ↔ `questions` | N:M | 通过 dataset_config 间接关联 |
