# 数学核心素养与素养水平官方定义说明

## 1. 文档目的

本文档用于后续数学题目“核心素养/核心素养水平”打标前的口径统一，重点回答一下问题：

1. 小学、初中、高中各自采用哪些官方素养集合。
2. 这些素养在课程标准中的官方定义是什么。

## 3. 各学段官方素养集合

### 3.1 小学阶段

根据《义务教育数学课程标准（2022年版）》“课程目标”与表 1，小学阶段核心素养主要表现为：

- 数感
- 量感
- 符号意识
- 运算能力
- 几何直观
- 空间观念
- 推理意识
- 数据意识
- 模型意识
- 应用意识
- 创新意识

备注：从义务教育课标的总框架看，小学阶段的“数感、量感、符号意识”可以视为“抽象能力”在小学阶段的具体表现项。依据是课标原文关于“数学眼光”的表述：  

> 在义务教育阶段，数学眼光主要表现为：抽象能力（包括数感、量感、符号意识）、几何直观、空间观念与创新意识。

同时，表 1 中又分别给出“小学阶段核心素养主要表现为：数感、量感、符号意识……”以及“初中阶段核心素养主要表现为：抽象能力……”。  
因此，从课程标准内部结构看，可以理解为：

- 小学阶段将抽象能力拆解为数感、量感、符号意识三个更具体的经验性表现项；
- 初中阶段则将其统摄为“抽象能力”这一概念化表述。

但在当前标注口径中，仍按 11 项保留，不合并。

### 3.2 初中阶段

根据同一标准，初中阶段核心素养主要表现为：

- 抽象能力
- 运算能力
- 几何直观
- 空间观念
- 推理能力
- 数据观念
- 模型观念
- 应用意识
- 创新意识

### 3.3 高中阶段

根据《普通高中数学课程标准（2017年版2020年修订）》“学科核心素养”，高中数学学科核心素养包括：

- 数学抽象
- 逻辑推理
- 数学建模
- 直观想象
- 数学运算
- 数据分析

## 4. 各学段素养的官方定义

### 4.1 义务教育阶段核心素养的官方总定义

《义务教育数学课程标准（2022年版）》先给出的是总框架，而不是像高中那样先逐项给出统一的“某素养是指……”体系。其官方总框架为“三会”：

- 会用数学的眼光观察现实世界
- 会用数学的思维思考现实世界
- 会用数学的语言表达现实世界

官方表述可概括为：

- “数学眼光”强调从现实世界中发现数量关系与空间形式，提出有意义的数学问题，并形成概念、关系与结构。
- “数学思维”强调建立逻辑联系，依据事实和规则推导结论，运用运算、推理等方法分析和解决问题。
- “数学语言”强调用数、式、符号、图表、模型、数据等方式简约而准确地描述、解释和交流现实世界。

其中，课程标准明确说明：

- 小学阶段侧重对经验的感悟；
- 初中阶段侧重对概念的理解。

这句话非常关键，意味着义务教育阶段的素养发展本身就是分学段、分阶段推进的。

### 4.2 小学阶段各素养的官方定义

以下内容依据《义务教育数学课程标准（2022年版）》表 1“核心素养的主要表现及其内涵”，保留官方原文。

| 素养 | 官方定义原文 |
| --- | --- |
| 数感 | 数感主要是指对于数与数量、数量关系及运算结果的直观感悟。能够在真实情境中理解数的意义，能用数表示物体的个数或事物的顺序；能在简单的真实情境中进行合理估算，作出合理判断；能初步体会并表达事物蕴含的简单数量规律。数感是形成抽象能力的经验基础。建立数感有助于理解数的意义和数量关系，初步感受数学表达的简洁与精确，增强好奇心，培养学习数学的兴趣。 |
| 量感 | 量感主要是指对事物的可测量属性及大小关系的直观感知。知道度量的意义，能够理解统一度量单位的必要性；会针对真实情境选择合适的度量单位进行度量，会在同一度量方法下进行不同单位的换算；初步感知度量工具和方法引起的误差，能合理得到或估计度量的结果。建立量感有助于养成用定量的方法认识和解决问题的习惯，是形成抽象能力和应用意识的经验基础。 |
| 符号意识 | 符号意识主要是指能够感悟符号的数学功能。知道符号表达的现实意义；能够初步运用符号表示数量、关系和一般规律；知道用符号表达的运算规律和推理结论具有一般性；初步体会符号的使用是数学表达和数学思考的重要形式。符号意识是形成抽象能力和推理能力的经验基础。 |
| 运算能力 | 运算能力主要是指根据法则和运算律进行正确运算的能力。能够明确运算的对象和意义，理解算法与算理之间的关系；能够理解运算的问题，选择合理简洁的运算策略解决问题；能够通过运算促进数学推理能力的发展。运算能力有助于形成规范化思考问题的品质，养成一丝不苟、严谨求实的科学态度。 |
| 几何直观 | 几何直观主要是指运用图表描述和分析问题的意识与习惯。能够感知各种几何图形及其组成元素，依据图形的特征进行分类；根据语言描述画出相应的图形，分析图形的性质；建立形与数的联系，构建数学问题的直观模型；利用图表分析实际情境与数学问题，探索解决问题的思路。几何直观有助于把握问题的本质，明晰思维的路径。 |
| 空间观念 | 空间观念主要是指对空间物体或图形的形状、大小及位置关系的认识。能够根据物体特征抽象出几何图形，根据几何图形想象出所描述的实际物体；想象并表达物体的空间方位和相互之间的位置关系；感知并描述图形的运动和变化规律。空间观念有助于理解现实生活中空间物体的形态与结构，是形成空间想象力的经验基础。 |
| 推理意识 | 推理意识主要是指对逻辑推理过程及其意义的初步感悟。知道可以从一些事实和命题出发，依据规则推出其他命题或结论；能够通过简单的归纳或类比，猜想或发现一些初步的结论；通过法则运用，体验数学从一般到特殊的论证过程；对自己及他人的问题解决过程给出合理解释。推理意识有助于养成讲道理、有条理的思维习惯，增强交流能力，是形成推理能力的经验基础。 |
| 数据意识 | 数据意识主要是指对数据的意义和随机性的感悟。知道在现实生活中，有许多问题应当先做调查研究、收集数据，感悟数据蕴含的信息；知道同样的事情每次收集到的数据可能不同，而只要有足够的数据就可能从中发现规律；知道同一组数据可以用不同方式表达，需要根据问题的背景选择合适的方式。形成数据意识有助于理解生活中的随机现象，逐步养成用数据说话的习惯。 |
| 模型意识 | 模型意识主要是指对数学模型普适性的初步感悟。知道数学模型可以用来解决一类问题，是数学应用的基本途径；能够认识到现实生活中大量的问题都与数学有关，有意识地用数学的概念与方法予以解释。模型意识有助于开展跨学科主题学习，增强对数学的应用意识，是形成模型观念的经验基础。 |
| 应用意识 | 应用意识主要是指有意识地利用数学的概念、原理和方法解释现实世界中的现象与规律，解决现实世界中的问题。能够感悟现实生活中蕴含着大量的与数量和图形有关的问题，可以用数学的方法予以解决；初步了解数学作为一种通用的科学语言在其他学科中的应用，通过跨学科主题学习建立不同学科之间的联系。应用意识有助于用学过的知识和方法解决简单的实际问题，养成理论联系实际的习惯，发展实践能力。 |
| 创新意识 | 创新意识主要是指主动尝试从日常生活、自然现象或科学情境中发现和提出有意义的数学问题。初步学会通过具体的实例，运用归纳和类比发现数学关系与规律，提出数学命题与猜想，并加以验证；勇于探索一些开放性的、非常规的实际问题与数学问题。创新意识有助于形成独立思考、敢于质疑的科学态度与理性精神。 |

### 4.4 高中阶段各素养的官方定义

以下内容依据本地 [普通高中数学课程标准（2017年版2020年修订）.docx](</C:/Users/29694/Desktop/Projects/素养知识点打标系统/数据/课标/普通高中数学课程标准（2017年版2020年修订）.docx>) 中“学科核心素养”部分整理。

#### 4.4.1 总定义

高中课标明确指出：

- 学科核心素养是育人价值的集中体现，是学生通过学科学习逐步形成的正确价值观、必备品格和关键能力。
- 数学学科核心素养是数学课程目标的集中体现，是具有数学基本特征的思维品质、关键能力以及情感、态度与价值观的综合体现。

#### 4.4.2 六项素养定义

| 素养 | 官方定义原文 |
| --- | --- |
| 数学抽象 | 数学抽象是指通过对数量关系与空间形式的抽象，得到数学研究对象的素养。主要包括：从数量与数量关系、图形与图形关系中抽象出数学概念及概念之间的关系，从事物的具体背景中抽象出一般规律和结构，并用数学语言予以表征。 |

## 5. 官方“素养水平”定义

### 5.1 义务教育阶段

义务教育数学课标没有像高中课标那样，为每一个素养统一设定“水平1/水平2/水平3”三级体系。

官方相关定义主要有三层：

1. 核心素养具有整体性、一致性和阶段性。  
   这意味着义务教育阶段更强调“分阶段发展”，而不是“全学段统一三级刻度”。

2. 小学阶段侧重经验感悟，初中阶段侧重概念理解。  
   这说明同一素养在小学和初中本身就不是完全同一层次的要求。

3. 学业质量是学生在完成课程阶段性学习后的学业成就表现，学业质量标准以核心素养为主要维度，结合课程内容，对学生表现特征进行整体刻画。  
   也就是说，义务教育的官方“水平”表达主要落在“学段目标 + 学业质量标准 + 学业要求”上，而不是逐项素养统一分成三级。

进一步说，义务教育课标对学业质量的官方组织方式是：

- 依据各阶段学生核心素养表现；
- 结合各学段课程目标及学业要求；
- 对不同学段学生学业成就的具体表现特征进行整体刻画。

因此，义务教育阶段的官方体系是“学段性、阶段性、整体性”的质量描述体系，不是“每项素养固定三级”的体系。

### 5.2 高中阶段

高中数学课标则明确建立了标准化的三级水平体系：

1. 学业质量是学生完成本学科课程学习后的学业成就表现。
2. 学业质量标准以本学科核心素养及其表现水平为主要维度，结合课程内容，对学生学业成就表现进行总体刻画。
3. 数学学业质量水平是六个数学学科核心素养水平的综合表现。
4. 每一个数学学科核心素养划分为三个水平。

这里需要特别说明：**高中阶段是有官方“素养水平定义”的。**  
它就在《普通高中数学课程标准（2017年版2020年修订）》附录 1“数学学科核心素养的水平划分”中，不仅有总说明，而且对六个素养分别给出了水平一、水平二、水平三的具体描述。

课标对三级水平的总说明是：

- 数学学业质量水平是六个数学学科核心素养水平的综合表现。
- 每一个数学学科核心素养划分为三个水平。
- 每一个水平是通过数学学科核心素养的具体表现和四个方面进行表述的。

这四个方面是：

- 情境与问题
- 知识与技能
- 思维与表达
- 交流与反思

由于六个素养的三级描述写法结构高度相似，这里只用“数学抽象”作示例，提炼三级水平的官方含义：

- **水平一：能够在熟悉的情境中，直接抽象出数学概念和规则；能够在特例基础上归纳并形成简单的数学命题；能够模仿学过的方法解决简单问题；能够在交流中结合实际情境解释相关抽象概念。**
- **水平二：能够在关联的情境中抽象出一般的数学概念和规则；能够将已知数学命题推广到更一般的情形；能够在新的情境中选择和运用数学方法解决问题；能够用一般概念解释具体现象。**
- **水平三：能够在综合的情境中抽象出数学问题，并用恰当的数学语言予以表达；能够在得到数学结论基础上形成新命题；能够针对具体问题运用或创造数学方法解决问题；能够用数学原理解释更复杂的现象。**

据此可以看出，高中三级水平的官方区分逻辑大体是：

- 水平一：熟悉情境中的直接抽象、基础理解与简单迁移
- 水平二：关联情境中的一般化、方法选择与较完整迁移
- 水平三：综合情境中的再创造、深层概括与创新性运用

官方还明确了这三级的使用场景：

- 水平 1：高中毕业应达到的要求，也是高中学业水平考试命题依据。
- 水平 2：高考要求，也是高考命题依据。
- 水平 3：高于一般毕业与高考要求，可作为更高层次选拔参考。
