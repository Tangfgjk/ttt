# V6 一阶段初版系统操作手册

更新时间：`2026-05-13`

## 1. 手册目的

本文档用于说明 K12 学科标注平台初版系统的本地启动方式、角色入口、主要页面和典型操作流程。

当前版本面向一阶段收尾演示和后续开发交接，重点说明系统“如何使用”，而不是展开底层设计细节。

## 2. 系统定位

本系统服务于 K12 学科题目的核心素养标注工作，覆盖题库导入、重复题治理、标注员培训、多人并行标注、争议复核、主动学习选题和训练监控。

系统当前支持三类角色：

| 角色 | 主要职责 |
| --- | --- |
| 系统管理员 | 管理题库、导入数据、处理重复题、查看可视化、启动训练与选题、治理题池和查看审核记录 |
| 标注员 | 通过培训准入后领取题目，完成核心素养及层级标注，查看自己的历史标注记录 |
| 复核员 | 领取有争议的题目，查看多人标注情况，提交最终复核结论，查看已复核记录 |

## 3. 本地启动

### 3.1 后端启动

进入后端目录：

```powershell
cd C:\Users\29694\Desktop\ttt\backend
```

安装依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -e .[dev]
```

.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --reload

| 配置项 | 推荐值 |

## 5. 系统管理员操作流程

### 5.1 项目总览

进入系统后，管理员首先查看“项目总览”。

该页面用于快速了解：

- 题库总体规模
- 标注进度
- 复核进度
- 主动学习和训练状态
- 下一步建议动作

### 5.2 导入中心

导入中心用于上传和处理题库文件。

推荐操作流程：

1. 进入“导入中心”。
2. 上传 Excel 或指定格式数据文件。
3. 查看导入批次状态。
4. 进入批次详情查看新增题目、重复候选和失败记录。
5. 对导入异常或候选重复题进行后续治理。

当前导入中心已支持分页展示，默认每页 `10` 条，便于处理较多导入记录。

### 5.3 判重复核

判重复核用于处理系统识别出的疑似重复题。

典型操作：

1. 查看待复核重复候选。
2. 对比原题与候选题的题干、来源和内容指纹。
3. 判断是否重复。
4. 提交复核结果。

复核结果会影响统一题池中的题目保留、合并或治理状态。

### 5.4 统一题池

统一题池是管理员查看全部题目的核心入口。

可用于：

- 按题目状态筛选
- 查看题目详情
- 查看来源批次
- 查看标注状态
- 跳转到相关治理页面

### 5.5 可视化

可视化页面用于查看题目 embedding 分布。

当前支持：

- 查看总题量、已嵌入题量、缺失嵌入数量
- 使用 PCA 等方式查看二维分布
- 按标注状态区分点位颜色
- 一键补全缺失 embedding

如果新导入题目后出现缺失 embedding，可在该页面执行补全。

### 5.6 训练监控

训练监控用于管理主动学习训练链路。

主要能力：

- 查看当前模型与模型版本数
- 查看训练样本数量
- 查看未标注候选数量
- 启动模型训练
- 查看训练日志和训练进度
- 执行低置信度预测选题
- 执行 CoreSet 选题
- 查看 CoreSet 历史任务、运行阶段和失败原因
- 查看题池治理批次并撤回不合适批次

当前默认训练参数：

| 参数 | 默认值 |
| --- | --- |
| Epochs | `20` |
| CoreSet 策略 | `K-Means 覆盖` |
| CoreSet 选题数 | `400` |

### 5.7 管理后台

管理后台主要用于系统治理，不再承载训练监控中的选题历史。

可查看：

- 审核日志
- 操作历史
- 管理员、标注员、复核员相关处理记录
- 系统治理状态

## 6. 标注员操作流程

### 6.1 我的工作台

标注员登录后首先进入“我的工作台”。

工作台展示：

- 当前待标注题数量
- 今日已完成数量
- 进入复核的题数量
- 当前建议动作

这些数据会按当前登录标注员实时更新。

### 6.2 培训准入

标注员正式标注前需要通过培训。

培训分为：

- 初中培训
- 高中培训

每个学段包含三个主要面板：

| 面板 | 作用 |
| --- | --- |
| 基础知识引导 | 学习核心素养定义、层级含义和引导样例 |
| 实战校准 | 一次只做一道题，完成该学段校准题 |
| 结果复盘 | 查看每次答题记录、题目得分、标准答案和逐素养差异 |

结果复盘支持：

- 选择某次历史答题记录
- 默认展示最新一次记录
- 全部重做
- 错题重做

错题重做只展示未通过题，但提交时会合并该次记录中已通过题的答案；只要最终整体达到通过线，也算培训通过。

### 6.3 标注工作台

通过培训后，标注员可以进入“标注工作台”领取题目。

典型流程：

1. 选择领取题目数量。
2. 点击领取题目。
3. 阅读题干。
4. 对每个核心素养选择 `0/1/2/3` 层级。
5. 如果忘记定义，可悬浮在素养名称上查看说明。
6. 提交标注。

层级说明：

| 层级 | 含义 |
| --- | --- |
| 0级 | 不体现该素养，或不是本题核心关注点 |
| 1级 | 有体现，但多为辅助理解或局部步骤 |
| 2级 | 支撑关键求解过程，对作答有明显作用 |
| 3级 | 决定整题理解或求解路径，是核心驱动力 |

### 6.4 我的标注记录

标注员可以在“我的标注记录”中查看：

- 已标注题目
- 自己提交的素养层级
- 是否进入复核
- 是否最终通过一致性判定
- 复核反馈

## 7. 复核员操作流程

### 7.1 我的工作台

复核员工作台展示：

- 当前待复核题数量
- 已完成复核数量
- 当前建议动作

数据按当前登录复核员实时更新。

### 7.2 标注复核

有争议的题目会自动进入复核队列。

复核员可以：

1. 查看待复核数量。
2. 选择每次领取多少道复核题。
3. 点击领取复核题。
4. 查看题目内容。
5. 查看三名标注员的标注情况和确信程度。
6. 重点处理存在争议的素养维度。
7. 提交最终复核结论。

如果某个素养已经由三人多数一致，系统可直接锁定，不需要复核员重复判断。

### 7.3 已复核题目

复核员可以查看自己已经处理过的题目，包括：

- 复核结论
- 原始标注分歧
- 提交时间
- 题目详情

## 8. 一致性规则简述

系统采用按素养维度独立判断的一致性规则。

对于每道题，每个素养都有一个 `0/1/2/3` 层级，其中 `0级` 表示不体现该素养。

三人标注完成后：

- 如果某个素养层级有至少两人一致，则该素养采用多数结果。
- 如果三个标注员在某个素养上三种意见均不同，则该素养进入争议。
- 只要题目存在争议素养，该题会进入复核员队列。
- 复核员只需要重点处理争议素养，已一致的素养可直接锁定。

## 9. 主动学习流程简述

当前系统主动学习流程为：

1. 使用已有金标数据训练初始模型。
2. 使用模型对未标注题进行预测。
3. 通过低置信度策略找出模型不确定题。
4. 通过 CoreSet 策略从未标注池中选择具有代表性的题。
5. 将选出的题加入待标注池。
6. 标注员完成标注，复核员处理争议题。
7. 形成新的高质量标注数据。
8. 周期性重新训练模型，进入下一轮主动学习。

CoreSet 当前支持全量与增量模式：

- 全量模式：从全部未标注题中选择代表性样本，适合阶段性重新选题。
- 增量模式：面向新导入数据或新增未标注题进行补充选题，适合日常持续更新。

## 10. 常见问题

### 页面数据加载不出来

优先检查：

- 后端是否启动
- 前端代理端口是否与后端端口一致
- `VITE_API_PROXY_TARGET` 是否指向正确地址
- 数据库连接是否正常

### 后端端口被占用

可以改用 `8001`：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --reload
```

前端同步设置：

```powershell
$env:VITE_API_PROXY_TARGET="http://127.0.0.1:8001"
```

### CoreSet 选题没有立即看到结果

CoreSet 已改为异步任务。

应在“训练监控”中查看：

- CoreSet 历史任务
- 当前运行阶段
- 失败原因
- 选题批次
- 题池治理记录

### 培训结果里某题金标看起来有争议

培训金标来自金标数据集。复盘页会显示标准层级和你的选择。

如果某题确实存在规则争议，建议后续补充“专家解释/金标理由”字段，方便培训阶段解释为什么某素养给 `0/1/2/3`。

- 管理员端可管理题库和主动学习链路。

- 复核员端可完成争议题复核。
- 主动学习、CoreSet、低置信度预测和训练监控已经形成可运行闭环。
