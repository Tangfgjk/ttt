## 当前版本定位

本版本不是单一页面原型，而是一个已经打通主要业务链路的初版系统：

- 管理员可以完成题库导入、判重复核、题池治理、训练监控和主动学习选题。
- 标注员可以完成培训准入、领取题目、提交标注和查看个人标注记录。
- 复核员可以领取争议题、参考三人标注情况并提交最终复核结论。
- 系统可以围绕金标数据、模型训练、低置信度预测和 CoreSet 选题形成主动学习闭环。

## 一阶段收尾判断

一阶段目标可以视为完成：系统已经具备可运行、可演示、可继续迭代的完整骨架和核心流程。

后续二阶段应重点关注正式评测、部署运维、安全权限、算法质量指标和更细粒度的数据治理。
