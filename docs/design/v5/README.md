## 当前进度

截至 `2026-05-12`，V5 已经完成或进入可联调状态的重点能力包括：

- 多人并行标注、三人多数聚合、争议题自动进入复核员队列
- 标注员培训与准入流程优化、素养说明随手可查、引导样例补充
- 标注员/复核员历史记录页与工作台实时数据
- CoreSet 全量异步任务化、历史任务追踪、失败原因与运行阶段可视化
- `kmeans / facility_location / graph_cut / moe / random` 的正式全量/增量选题路径
- 导入后 embedding 增量补全与主动学习概览联动刷新

## V5 阶段仍建议继续推进

- 正式评估体系：固定测试集、交叉验证、重复实验与对比报表
- 算法质量监控：Coverage / Redundancy / MMD 等指标在线化
- 模型与任务治理：更细粒度回滚、审计、失败恢复与备注体系
- 上线前安全：密码加密、权限边界、运维监控与告警
