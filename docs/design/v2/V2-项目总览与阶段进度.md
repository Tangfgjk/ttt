# V2 项目总览与阶段进度

## 1. 项目定位

本项目是一个面向初中数学题目标注、统一题池治理、主动学习推荐与训练监控的系统。

当前系统采用：

- 后端：`FastAPI + SQLAlchemy + Alembic + MySQL`
- 前端：`React + TypeScript + Vite + Ant Design`
- 架构：单仓库、前后端分离、模块化单体后端

项目的核心目标不是只做一个标注页面，而是逐步建设下面这几条完整链路：

- 原始数据导入
- 统一题池构建
- 题目判重
- 人工标注与聚合
- 推荐与训练
- 管理与可视化

---

## 2. 当前系统结构

当前仓库结构如下：

```text
ttt/
  backend/
  frontend/
  docs/
    design/
      v1/
      v2/
```

其中：

- `backend/`
  - 后端 API、数据库模型、迁移脚本、导入与判重服务

- `frontend/`
  - 前端页面、角色登录、管理端与用户端工作台骨架

- `docs/design/v2/`
  - V2 设计、实施、进度、规则与操作文档
