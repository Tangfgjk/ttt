# V2 项目运行操作手册

## 4. 第一步：启动后端

### 4.1 准备后端环境变量

在 `backend/` 目录下创建 `.env` 文件，内容如下：

```env
APP_NAME=TTT Annotation Backend
APP_ENV=local
APP_DEBUG=true
API_V1_PREFIX=/api/v1
DATABASE_URL=mysql+pymysql://root:541521@127.0.0.1:3306/competency_annotation_dev
REDIS_URL=redis://127.0.0.1:6379/0
CELERY_BROKER_URL=redis://127.0.0.1:6379/1
CELERY_RESULT_BACKEND=redis://127.0.0.1:6379/2
ENABLE_DOCS=true
```

说明：

- 当前阶段即使 Redis 没启动，后端主服务也可以先跑起来
- 但数据库必须可连接

### 4.2 进入后端目录

```powershell
cd C:\Users\29694\Desktop\ttt\backend
```

### 4.3 激活虚拟环境

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4.4 如果首次运行，安装后端依赖

```powershell
pip install -e .[dev]
```

### 4.5 执行数据库迁移

```powershell
alembic upgrade head
```

### 4.6 启动后端服务

```powershell
uvicorn app.main:app --reload
```

### 4.7 验证后端是否启动成功

打开浏览器访问：

- `http://127.0.0.1:8000/`
- `http://127.0.0.1:8000/docs`

若能打开，说明后端启动成功。

## 5. 第二步：启动前端

### 5.1 确认 Node.js 与 npm 可用

在新的终端中执行：

```powershell
node -v
npm -v
```

若能显示版本号，说明前端运行环境正常。

### 5.2 准备前端环境变量

在 `frontend/` 目录下创建 `.env` 文件，内容如下：

```env
VITE_API_PROXY_TARGET=http://127.0.0.1:8000
```

### 5.3 进入前端目录

```powershell
cd C:\Users\29694\Desktop\ttt\frontend
```

### 5.4 安装前端依赖

```powershell
npm install
```

### 5.5 启动前端开发服务器

```powershell
npm run dev
```

### 5.6 验证前端是否启动成功

打开浏览器访问：

- `http://127.0.0.1:5173/`

若能打开登录页，说明前端启动成功。

## 11. 常见问题

### 11.1 后端能启动，但访问题库接口报数据库错误

原因通常是：

- `.env` 中的 `DATABASE_URL` 写错
- MySQL 没启动
- 数据库名不对

请确认：

```env
DATABASE_URL=mysql+pymysql://root:541521@127.0.0.1:3306/competency_annotation_dev
```

### 11.2 终端里 `node` 或 `npm` 找不到

请确认：

- 已安装 Node.js
- 环境变量 `Path` 中包含：

```text
C:\Program Files\nodejs
```

### 11.3 前端能打开，但登录失败

请先确认：

- 后端是否已运行
- 登录接口地址是否正常
- 当前数据库中是否已自动初始化默认开发账号

### 11.4 登录后页面不对

这是角色分流逻辑决定的：

- `admin` 会进管理端首页
- `annotator` 与 `reviewer` 会进用户端工作台
