# V4.8 训练页与试题嵌入可视化优化总结

记录日期：2026-05-10

## 1. 本轮目标

本轮工作聚焦两条体验优化主线：

1. 优化试题嵌入可视化页面的加载性能，降低每次进入页面重新计算和重新绘制的等待时间。
2. 优化训练页与训练监控页的管理体验，让默认行为、设备语义、名称展示和布局更符合管理员使用习惯。

## 2. 试题嵌入可视化性能优化

### 2.1 背景问题

在题量达到 4 万级后，可视化页存在两个明显问题：

1. 每次进入页面都会重新请求并重新计算分布结果，等待时间较长。
2. 图上点数过多时，前端重绘成本较高，刷新与切换体验偏慢。

### 2.2 后端缓存优化

在 `VisualizationService.question_distribution()` 中新增了分布结果签名缓存。

缓存键由以下信息共同决定：

- embedding 模型 ID
- 降维方法
- 标注状态筛选
- limit
- 当前状态统计摘要
- 最新 embedding 计算时间
- 最新题目更新时间
- 最新题干内容更新时间

只要这些关键信息没有变化，就直接复用上一次结果，不再重新做全量查询和降维。

当前策略特点：

- 缓存命中条件严格，不会因为旧缓存导致页面看到过期结果
- 缓存容量有限，避免常驻过多大对象
- 管理员仍然可以通过“刷新图表”按钮主动触发刷新

### 2.3 前端请求缓存优化

前端对可视化查询也补充了更积极的缓存策略：

- 页面再次进入时优先复用缓存结果
- 关闭窗口聚焦自动重查
- 关闭重复 mount 时的立即重查
- 保留手动刷新入口

这样页面从“每次重来”调整为“默认复用、需要时再刷新”。

### 2.4 大点数绘图优化

针对 4 万点级别散点图，补充了 ECharts 渐进式绘制参数：

- `progressive`
- `progressiveThreshold`
- `animationThreshold`

优化后，大点数渲染的卡顿情况明显减轻，页面滚动与交互也更平滑。

## 3. 可视化与统一题池联动

### 3.1 新增题目详情跳转

在“选中试题详情”区域新增了：

- `跳转到统一题池查看详情`

点击后会带着 `question_id` 跳转到统一题池页。

### 3.2 统一题池支持 question_id 直达

统一题池页新增了对 `question_id` 查询参数的支持：

- 当 URL 中存在 `question_id` 时，页面会自动定位这道题并打开详情抽屉
- 关闭抽屉后会自动移除 `question_id`

这样管理员就能从“题目空间分布”直接进入“统一题池详情查看”，形成真正的跨页面工作流。

## 4. 训练页与训练监控体验优化

### 4.1 合并金标默认开启

训练模型表单中的“合并金标”已改为默认打开：

- 首次进入页面默认开启
- 如果管理员手动修改，会继续记住本地选择

这更符合当前系统阶段的实际使用习惯，因为金标样本仍然是训练集的重要组成部分。

### 4.2 训练设备 Auto 语义明确化

当前 `Auto` 的实际含义已明确为：

- 优先使用 GPU worker 环境
- 如果该环境中 CUDA 可用，则走 GPU
- 如果 GPU 不可用，则回退到 CPU

也就是说：

- `CPU`：强制只用 CPU
- `GPU`：强制走 GPU worker 环境
- `Auto`：优先 GPU，可用则上，不可用则退回 CPU

这比“语义不清晰的自动选择”更符合管理员预期。

### 4.3 顶部摘要卡片对齐优化

训练监控页顶部卡片重新整理后：

- 当前模型
- 训练样本
- 未标注候选
- 模型版本数

在高度、内容密度和对齐上更加一致，不再因为第一个卡片模型名过长而破坏整行布局。

### 4.4 长名称统一短名展示

针对训练任务名和模型版本名过长的问题，当前已统一为：

- 短名展示
- Tooltip 展示完整信息

统一应用到：

- 当前模型卡片
- 训练任务表中的关联模型
- 模型版本表第一列
- 模型版本表中的来源任务
- 训练任务详情中的生成模型

这样既保留了关键信息，也避免长串名称把表格和卡片撑乱。

## 5. 当前收益

本轮优化后，系统在两个方面提升明显：

### 5.1 可视化页

- 再次进入页面不再频繁全量重算
- 大点数页面渲染更平滑
- 从空间分布到统一题池详情的工作流被打通

### 5.2 训练与监控页

- 默认训练参数更符合当前项目阶段
- 设备选择语义更清晰
- 顶部布局更整齐
- 模型名和任务名更可读

## 6. 后续建议

下一阶段可以继续推进以下优化：

1. 可视化页增加“抽样首屏 + 局部放大后看更多点”的渐进式展示模式
2. 可视化页增加更多联动信息，例如知识点、学科、年级快速筛选
3. 训练监控页为模型版本补充更多治理能力
   - 备注
   - 对比
   - 废弃
   - 回滚
4. 统一题池详情中增加更多来源上下文，便于从可视化页跳转后直接研判题目价值
