# V3 设计与交付文档

## 1. 目录定位

`v3/` 目录不是替代 `v1/` 与 `v2/`，而是对前两阶段的实施结果总结与下一阶段执行基线。

- `v1/`
  - 保存最初的系统设计输入文档与第一轮分析基线
- `v2/`
  - 保存实施设计、数据库设计、导入方案、判重规则、运行手册等落地文档
- `v3/`
  - 说明当前真实进度、已完成能力、未完成能力和下一阶段优先级
