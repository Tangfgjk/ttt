## 当前版本定位

V8 的重点不是新增一个选题按钮，而是重新定义 CoreSet 增量更新的业务语义：

- 选题对象始终是当前全部未标注题池
- 增量对象是算法中间状态、向量缓存、聚类/覆盖结构和局部更新计算
- 不同算法的增量基线彼此隔离，不能跨算法复用
- 导入新未标注题后，系统应更新当前题池分布，并从更新后的全池中重新选择代表题

## 阶段目标

先形成可解释、可实现、可逐步落地的设计方案，再分阶段改造现有 CoreSet 逻辑，避免继续沿用“只从新增题里选题”的错误语义。

同时，本阶段也补齐了系统登录注册入口，支持标注员自助注册、培训前置准入和基础忘记密码引导。
