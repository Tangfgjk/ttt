
# V8-登录注册与标注员自助准入实现说明

## 1. 目标

本次 V8 补齐系统最基础的身份入口，目标如下：

- 首次打开系统时，未登录用户必须先进入登录页
- 页面自助注册仅开放给标注员
- 系统管理员与复核员账号继续由系统固定维护，不在页面开放注册
- 新注册标注员注册成功后可直接登录
- 未完成培训的标注员默认进入培训准入页，培训通过后再进入正式标注流程
- 忘记密码先采用“联系管理员重置”的轻量方案

## 2. 业务规则

### 2.1 角色约束

- `admin`：系统管理员，固定账号
- `reviewer`：复核员，固定账号
- `annotator`：标注员，可在页面注册

注册接口不会接受前端传入的角色字段，后端统一强制写入：

```text
role = annotator
training_scope = none
is_active = true
is_verified = true
```

### 2.2 注册规则

- 注册字段：`username`、`password`、`confirm_password`
- 用户名长度限制：3-20 位
- 用户名字符限制：中文、字母、数字、下划线
- 系统保留用户名不可注册，例如：`admin`、`reviewer`、`管理员`
- 密码长度至少 6 位
- 两次密码必须一致

### 2.3 登录后跳转规则

- 管理员：进入 `/admin/overview`
- 已完成培训的标注员、复核员：进入 `/workspace`
- 未完成培训的标注员：进入 `/annotator-training`

## 3. 前端实现

### 3.1 新增页面

- `/login`：登录页
- `/register`：标注员注册页
- `/forgot-password`：忘记密码说明页

### 3.2 路由守卫

- `RequireAuth`
  - 未登录时统一跳转 `/login`
- `PublicOnly`
  - 已登录用户访问登录/注册/忘记密码页时，按角色与培训状态自动跳回业务页
- `RequireTraining`
  - 标注员未完成培训时，拦截标注相关页面并引导到培训页

### 3.3 交互说明

- 登录页不再展示开发账号与默认密码
- 注册成功后直接建立前端会话，并自动进入培训准入页
- 忘记密码页提供用户名输入与操作提示，提交后统一提示联系管理员重置密码

## 4. 后端实现

### 4.1 新增接口

- `POST /api/v1/auth/login`
- `POST /api/v1/auth/register`
- `POST /api/v1/auth/forgot-password`

### 4.2 默认账号策略

后端启动时仍会确保固定账号存在，但不再自动灌入开发标注员账号。默认保留：

- 管理员账号
- 复核员账号

标注员账号改为通过页面注册进入数据库。

## 5. 数据库变更

用户表本次补充或调整以下字段：

- `email`：改为可空，支持仅用户名注册
- `must_change_password`：为后续管理员重置密码保留扩展位
- `last_login_at`：记录最近登录时间

对应 Alembic 迁移：

- `20260518_0012_add_user_registration_fields.py`

## 6. 忘记密码方案

当前版本不接入邮箱或短信，也不开放无验证自助重置，避免带来更大的账号风险。现阶段流程为：

1. 用户打开忘记密码页
2. 输入用户名并提交
3. 系统统一提示联系管理员重置密码
4. 后续如需增强，可在此基础上追加管理员重置页面、首次登录强制改密、邮箱或短信校验

## 7. 验证与风险说明

### 7.1 已完成验证

- 前端 TypeScript 类型检查通过
- 后端认证相关文件可完成语法编译

### 7.2 当前限制

- 当前密码仍按现有约定明文保存，仅适合作为阶段性方案
- 本轮未接入短信、邮箱或正式 token 鉴权体系
- 忘记密码暂为管理员协助重置流程，尚未提供完整后台重置页面

## 8. 后续建议

后续建议按以下顺序继续增强：

1. 将密码存储从明文切换为哈希
2. 增加管理员重置标注员密码页面
3. 接入首次登录或重置后强制改密
4. 根据实际需求再决定是否接入邮箱或短信验证
