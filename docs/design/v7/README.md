# V7 文档

`docs/design/v7/` 用于沉淀二阶段启动前的部署、运维和生产化设计材料。

当前系统已经具备本地可运行、多人业务流程基本打通的初版能力。V7 阶段的重点不再是继续补单个页面，而是把现有系统整理成一套可部署、可迁移、可维护的多人协作服务栈。

## 当前版本定位

V7 不是新的业务原型版本，而是围绕“如何从本地开发版走向多人可用部署版”展开的工程化设计阶段，重点包括：

- 明确前后端、数据库、缓存、后台任务的服务边界
- 规划 Docker Compose 形态下的目录、镜像、网络、卷和环境变量
- 梳理从本地运行模式切换到服务器常驻服务模式的改造重点
- 为后续的正式鉴权、安全加固、备份和发布流程留出扩展空间

## 阶段目标

本阶段希望先形成一套可落地的部署设计蓝图，使系统能够较低成本地完成内网多人协作部署，并为后续正式生产化改造提供清晰路线。
